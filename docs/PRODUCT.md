# 产品定位与边界

## 产品定位

**流光 `Lumakey`** 是一款面向 Apple Silicon Mac 用户的**菜单栏常驻、全局热键驱动的 iOS 液态玻璃效率快捷工具**（对标 Kitty Tools 与 uTools）：
- 在**主入口形态**上，应用以 `LSUIElement` 驻留于右上角菜单栏，任何桌面或全屏应用之上按下 `⌥Space` 即可唤起真正 `28pt` 连续曲率大圆角、可任意拖拽的液态玻璃悬浮控制面板；
- 在**单一全搜中枢**上，通过统一搜索框 + `Tab` 轻量过滤胶囊（`全部` / `文件` / `剪贴板` / `插件`），一次性并发检索本地化拼音应用、数学与进制/单位换算、端口检测、Everything 多根目录文件（免前缀）、剪贴板历史、内置 `Mos` 鼠标命令与扩展插件；
- 在**独立阅读与媒体窗口**上，提供零 `WKWebView` 的纯原生 Markdown/代码阅读器、只读看图窗与影院视频播放器，支持 **图片/视频窗口置顶、`520×300` 小窗浮层与同目录视频播放列表连播**，关闭窗口即刻销毁内存；
- 在**系统效率内置插件与扩展生态**上，内置独立区分物理鼠标与触控板的 **Mos 鼠标平滑/反转插件**、**系统脉搏监控悬浮窗 (`⌥M`)**（支持顶部精简悬停展开、屏幕贴边自动隐藏与菜单栏实时读数）、**内置网络流量与去向监控 (`⌥N`)**、**独立应用缓存管理**，以及原生 stdio MCP 服务器 (`lumakey-mcp`)。
- 在**文件与外置磁盘工作台 (`⌥E`)**上，定位为按需打开、关闭即卸载的**附加工具**，支持列表/网格/紧凑多视图、多字段排序、媒体类型筛选、右侧居中图片/视频实时预览、批量重命名预检与外置 NTFS 只读护航。
- 所有可选桌面悬浮窗与菜单栏实时读数在**刚安装时默认关闭**，可在设置中心按需自由开启。

## 核心使用场景

1. **Bento 控制中心与统一全搜一步直达**：空状态呈现可拖拽 3×2 Bento 磁贴（含全盘文件、剪贴板、Mos 鼠标实时状态、截图钉屏、离线识字与附加文件台）与高频应用坞；输入文字即可同时命中应用、文件名、剪贴板条目、数学/换算、端口占用与系统命令。
2. **内置 Mos 物理鼠标平滑与滚轮反转**：自动识别物理鼠标滚轮并保留触控板自然滚动，支持 120Hz 高帧率平滑滚动、`⇧` 横向、应用排除与 `mos` 搜索关键词秒切换。
3. **Markdown / 代码 / 图片 / 视频独立窗口打开**：选中 `.md`、代码文件、图片或视频，回车或点击侧边预览镜「独立窗口打开」，即可在原生排版与大纲窗口中流畅阅读、切换同级文件。
4. **空闲自洁与最优内存架构**：浮窗隐藏 30s 销毁、索引空闲 90s 或内存告警自动卸载、子进程超限即杀、独立窗口关闭即释放 `contentView` 与堆页。
5. **QQ 式原生截图标注、取色、OCR 与原位钉屏 (`⌥A` / `⌥O`)**：支持冻屏窗口吸附、像素放大镜取色（`C` 键复制 `#HEX`）、矩形/椭圆/箭头/画笔/荧光笔/马赛克/序号/文字实时标注、离线 OCR、前景抠图及选区原位钉图置顶。
6. **外置 NTFS 与文件工作台（附加工具 `⌥E`）**：按需呼出独立双栏窗口，安全识别只读 NTFS 卷并提供批量重命名预检，关闭窗口后立即回收工作台内存。

## 明确的产品边界（不做清单）

为保持产品轻量、专注与 Clean Code 可维护性，`Lumakey` 明确**不做**以下功能：
- **不把主窗做成重型文件管理器**：快捷工具中枢是第一入口，双栏文件管理仅作为按需唤起的附加工作台。
- **不拆分孤立多套搜索框**：所有高频检索收敛到同一主输入流，通过轻量过滤胶囊聚焦范围。
- **不引入 WebKit / 浏览器内核渲染本地文档**：拒绝为 Markdown 预览拉起数百 MB 的 `WKWebView` XPC 进程。
- **不做图像编辑与视频剪辑**：仅提供无损只读看图与高效播放体验。
- **不做跨平台 / x86_64 兼容**：仅支持 `macOS 14.0+` 与 `arm64`。
- **不做无确认的后台常驻建库服务或冒险强写 NTFS**：不安装 `launchd` 守护进程，不绕过脏标记强行写挂载 NTFS 卷。
